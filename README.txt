ADD ANOTHER VIDEO
In index.html find the comment "TO ADD ANOTHER VIDEO", copy the <figure> block above it,
paste it below the comment, and replace OF_AARaifcs with the new video ID
(youtu.be/THIS_PART?si=... ). Unlisted videos work.

HOSTING FREE ON GITHUB PAGES
1. Create a free account at github.com.
2. New repository > name it e.g. michela-harp > Public > Create.
3. "uploading an existing file" > drag in index.html, favicon.svg and the images folder > Commit.
4. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root) > Save.
5. After ~1 minute your site is live at https://YOUR-USERNAME.github.io/michela-harp/

FORM (FormSubmit.co, free)
After the site is live, submit the form ONCE yourself. FormSubmit emails
michelavella.harp@gmail.com an activation link (check Spam/Promotions). Click it.
From then on every enquiry arrives in your inbox. The form does not work from a
double-clicked local file, only once published.
